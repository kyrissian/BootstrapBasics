## 📌 Project Overview

This project demonstrates the use of Bootstrap components and utilities to create a responsive and visually organized webpage. The page includes a navigation bar, registration form, responsive table, images, and utility buttons.

The project was built using:

* HTML5
* CSS3
* Bootstrap 5
* Visual Studio Code

---

## ✨ Features Included

### Responsive Navigation Bar

* Collapses into a hamburger menu on smaller screens
* Includes Home, About, and Contact links

### Registration Form

* First Name and Last Name fields displayed side-by-side using Bootstrap Grid
* Email and Password fields marked as required
* Terms and Conditions checkbox
* Green Submit button using `btn-success`

### Responsive Table

* Bootstrap styled table
* Hard-coded sample user data
* Striped rows for readability
* Hover effect on rows
* Responsive scrolling on smaller screens

### Image Section

* Responsive full-width image using `img-fluid`
* Circular image using `rounded-circle`

### Utility Buttons

* One button visible on all screen sizes
* One button hidden on small screens using Bootstrap display utilities

## 🚀 How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. View the webpage in your browser.
